# NOTICE

## Project

osep_math is an educational platform where elementary-school students learn
the five-stage mathematical conjecturing process (example construction,
conjecturing, validation, generalization, justification) by modifying
partially completed Scratch projects, guided by a local AI tutor.

Project name: osep_math

Project repository: https://github.com/bai-collab/osep_math

Derived from: https://github.com/bai-collab/osep-judge
