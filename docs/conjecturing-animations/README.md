# 臆測五階段教學動畫

國小五年級數學的學生版網頁動畫，帶學生走過臆測教學的五個階段：

造例 → 提出猜想 → 效化 → 一般化 → 證實

## 線上觀看

<https://bai-collab.github.io/osep_math/conjecturing-animations/>

打開總目錄 `index.html`，選一支動畫播放。也可以下載這個資料夾，用瀏覽器直接開 `index.html`（不需安裝；字型會從網路載入，離線時改用電腦內建字型）。

## 先看這兩支

| 動畫 | 檔案 | 長度 | 內容 |
|---|---|---|---|
| 臆測五階段在做什麼？ | `v2/intro-five-stages/index.html` | 2 分 31 秒 | 每一階要做什麼、交出什麼；任何單元前都可以播 |
| 一個人和 AI 走臆測五階段 | `v2/student-ai-five-stages/index.html` | 2 分 34 秒 | 一位學生和 AI 導師一問一答走完五階段；AI 導師只問不答，依學生的證據決定能不能進下一階 |

## 各單元：兩種版本

| 版本 | 什麼時候播 | 內容 |
|---|---|---|
| 🟠 課前暖身 | 單元開始**之前** | 用一個與本單元無關的暖身題練習五個步驟，最後只發下本單元任務，**不揭示答案** |
| 🟢 單元後講解 | 單元上完**之後** | 回顧全班怎麼一步步找到規律，**會揭示本單元的規律**，請勿在課前播放 |

| 單元 | 課前暖身 | 單元後講解 |
|---|---|---|
| 第二單元 倍數與因數 | `v2/u02-pre/`（連續奇數相加，L 形方塊補成正方形） | `v2/u02-post/`（百數表與個位轉盤） |
| 第四單元 公倍數與公因數 | `v2/u04-pre/`（長寬都變 2 倍，切成 4 塊原圖） | `v2/u04-post/`（兩隻青蛙在數線上一起落腳） |
| 第六單元 整數四則運算 | `v2/u06-pre/`（握手問題，新來的人拉紅線） | `v2/u06-post/`（兩塊點陣併成一塊） |
| 第七單元 擴分、約分與分數加減 | `v2/u07-pre/`（奇數＋奇數，珠子兩兩配對） | `v2/u07-post/`（紙帶切細、合粗） |

每支約 2.5 分鐘，分成 12～13 段。

## 操作

- 播放／暫停、上一段／下一段、全螢幕；「進度條」可拖到任一時間點。
- 「標註工具」可以在畫面上畫線、寫字，討論時使用（只留在這一頁，重新整理就消失）。
- 鍵盤：空白鍵播放／暫停，← → 換段，F 全螢幕。

## 說明

- 每支動畫是單一 HTML 檔，畫面上的算式、判斷與數量都由程式計算。
- 動畫中的方塊、珠子、青蛙、漏斗等是視覺比喻；畫面標「示意」的數字只是示意。
- 「一個人和 AI」版本的對話是依導師回應規準改寫的示範，不是真實紀錄。
- 內容依據臆測五階段教學設計稿改編，為教學設計稿，尚未在課堂試用。
- 舊版翻頁式動畫（2026-10-16）仍保留在同一資料夾（`unit-0X-*.html`），總目錄最下方可找到。
- `osep-math-student-guide.html`：第一次使用 osep_math 的學生操作教學。
