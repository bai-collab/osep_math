# 臆測五階段教學動畫

國小五年級數學的學生版網頁動畫，帶學生走過臆測教學的五個階段：

造例 → 提出猜想 → 效化 → 一般化 → 證實

## 線上觀看

<https://bai-collab.github.io/osep_math/conjecturing-animations/>

打開總目錄 `index.html`，選單元和版本即可播放。也可以下載這個資料夾，用瀏覽器直接開 `index.html`（不需網路、不需安裝）。

## 第一次使用 osep_math：學生操作教學

`osep-math-student-guide.html`（20 步）：教學生怎麼操作 osep_math 編輯器——填學生代號、選單元、照黃色提示條一步一步做、改程式與補積木（要貼緊接上）、執行並回答問題、填右邊面板、按「完成本階段」，以及卡住時怎麼求助。畫面是簡化的示意圖，不含任何單元的結論，課前可以放心播放。

## 兩種版本

| 版本 | 什麼時候播 | 內容 |
|---|---|---|
| 🟠 課前暖身 | 單元開始**之前** | 用一個與本單元無關的暖身題練習五個步驟，最後只發下本單元任務，**不揭示答案** |
| 🟢 單元後講解 | 單元上完**之後** | 回顧全班怎麼一步步找到規律，**會揭示本單元的規律**，請勿在課前播放 |

## 操作

- 「下一步／上一步」逐段推進，或按「自動播放」（每步 9 秒）。
- 點上方的階段名稱可以直接跳到該階段。
- 鍵盤：← → 換步驟，空白鍵開關自動播放。
- 分享某一步：在網址後面加 `?step=12`。
